[내 포트폴리오 직접 고치는 법]

1. 글, 프로젝트, 연락처는 전부 content.js 하나에 있어요.
   - VS Code나 텍스트 편집기로 열어서 "따옴표" 안의 글자만 바꾸세요.
   - 따옴표, 쉼표, 대괄호 [ ] 는 지우지 마세요. 지우면 화면이 안 나와요.

2. 사진 바꾸기 / 추가하기
   - 사진을 images 폴더에 넣어요 (영어 파일 이름, 띄어쓰기 없이. 예: bu-1.jpg)
   - content.js 에서 cover: "bu-1.jpg" 처럼 파일 이름만 적어요.

3. 프로젝트 추가하기
   - content.js 의 PROJECTS 안에서 { id: ... } 부터 }, 까지 블록 하나를 복사해서 붙여넣어요.
   - id 를 새 이름으로 바꿔요 (영어 소문자, 예: "my-new-project").
   - 메인 페이지에 카드가 자동으로 생기고, 클릭하면 그 프로젝트 페이지가 열려요.

4. 작품 추가하기 (프로젝트 페이지 안 그리드)
   - works: [ ] 안에 한 줄씩:
     ["파일이름.jpg", "제목", "재료 · 크기", "짧은 설명"],

5. 고친 다음 확인
   - index.html 을 브라우저로 열어서 확인 → GitHub Desktop에서 Commit → Push
   - 1~2분 뒤 사이트에 반영돼요.

화면이 하얗게 나오면 대부분 content.js 에서 따옴표나 쉼표가 빠진 거예요.
